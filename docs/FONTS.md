# Font register

> Generated by `scripts/font-register.py` from `skins-v2/*.yaml` —
> do not edit by hand; re-run the script after any skin change.
> Chroma ships no font binaries: a skin only names families, and
> rendering resolves through whatever the operating system provides.

Used by = the number of skins naming the family in any of
`fontSans` / `fontMono` / `fontDisplay`, out of every skin in the
catalogue. Every licence statement was fetched from the cited page
with curl on 2026-10-20; `UNVERIFIED` means the licence could not
be confirmed from a public page and is never a guess.

## Emoji fallbacks, not typography

These names appear at the end of skin stacks as system emoji
fallbacks — a terminal or surface substitutes whatever the
machine provides (`Apple Color Emoji`, `Segoe UI Emoji`, `emoji`).
They are listed here for completeness, with the same skin counts:

- `Apple Color Emoji` — named by 94 skin(s) (sans 94, mono 94) — licence UNVERIFIED
- `Segoe UI Emoji` — named by 94 skin(s) (sans 94, mono 94) — licence UNVERIFIED
- `emoji` — named by 94 skin(s) (sans 94, mono 94) — licence UNVERIFIED

No portability claim is made for any family in this register: a
machine without, say, Cascadia Mono ends on a generic and the skin
still renders. Nothing here is about installing or fetching fonts.
